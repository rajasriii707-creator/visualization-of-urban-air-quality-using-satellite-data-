About the project

This project visualizes urban air quality using satellite data. It helps understand pollution levels and identify critical areas.

Data Sources

Satellite data from NASA and pollution data from CPCB are used for analysis.

Methodology

Data is collected,cleaned,processed and visualized to show air quality levels in different areas.

Conclusion

This project helps identify pollution hotspots and supports environmental decision making.
